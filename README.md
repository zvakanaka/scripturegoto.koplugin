# scripturegoto.koplugin

A KOReader plugin that jumps to or previews scripture references from
links or highlighted text.

## Features

- **Go to scripture** — tap a supported scripture link, or highlight a
  plain-text reference (e.g. "Isaiah 53:5"), then jump straight to the
  matching chapter/verse in a scripture EPUB you configure per volume.
- **Preview scripture** — same triggers, but shows the verse(s) or whole
  chapter(s) in a floating window instead, no EPUB required. Text is
  downloaded on first use from
  [bcbooks/scriptures-json](https://github.com/bcbooks/scriptures-json)
  and cached locally.

- **Search scriptures** — the Search tab (magnifier) → **Search
  scriptures…**, in a book or the file browser (or bind "Scripture Goto: search scriptures" to a
  gesture), from a book or the file browser:
  - a query with a number in it is read as a Gospel Library-style
    shortcut: "ne37" offers 1 Nephi 3:7, 2 Nephi 3:7, 3 Nephi 3:7,
    4 Nephi 1:37 and Nehemiah 3:7; "1ne37", "jn316", "dc76" and
    "alma 32:21" work too
  - anything else is a full-text search for verses containing all of the
    words, across all five volumes. The first search downloads the text
    (if needed) and builds a word index once (about 10 MB in all); after
    that, searches are instant.

  Tap a result to go to it (or preview it, if no EPUB is set for that
  volume); hold it to preview.

Landing on a verse tints the whole verse, or verse range, not just its
number. It's a visual mark only (not a real selection, so taps and menus
behave normally) and stays until you close the book or jump somewhere else.

Both work for a single verse, a verse range or list ("Alma 40:11-14",
"Isa. 24:21, 22"), a whole chapter, or a chapter range ("Ecclesiastes
3-4").

## Supported links

- **ChurchofJesusChrist.org** study links, including verse/chapter ranges
- **Bible Gateway**
- **YouVersion / Bible.com**

Highlighted plain text is also recognized against common book names and
abbreviations (e.g. "Isa.", "D&C", "1 Ne.", "JST M").

## Installation

Copy `scripturegoto.koplugin/` into KOReader's `plugins/` directory.

## Configuration

More tools → **Scripture Goto** → **Scripture EPUBs** lets you set the EPUB used for each
scripture volume (`ot`, `nt`, `bofm`, `dc-testament`, `pgp`).

## Updates

Builds that include an update server let you update from inside KOReader:
More tools → Scripture Goto → **Check for updates**. It downloads the new
version over a certificate-pinned HTTPS connection, checks its SHA-256,
replaces the plugin folder (keeping one backup beside it), and asks to
restart KOReader. Builds without an update server (e.g. straight from
this repository) just say updates aren't configured.

## Development

See [`test-books/README.md`](test-books/README.md) for the dev
environment, running the plugin locally, and test fixtures. The demo GIFs
above are regenerated by [`tools/demo-gifs/`](tools/demo-gifs/README.md).

To make a release: bump `scripturegoto.koplugin/VERSION` (`YYYY.MM.DD-N`),
run `scripts/package-plugin.sh`, fill in `notes` in `dist/version.json`,
and upload `dist/scripturegoto.koplugin.tar.gz` and `dist/version.json` to
the update server (the tarball first, then the manifest). Self-update needs
the untracked `update-server.txt` (manifest URL) and `update-ca.pem`
(the server's certificate) in the plugin folder when packaging.
